# 知识库 RAG（第一~四阶段，本轮新增）：以下为「可选依赖」。
#   pip install chromadb          # 本地向量库（必需，缺了知识库自动降级为不启用）
#   pip install pypdf             # 解析 PDF 才需要
#   pip install python-docx       # 解析 .docx 才需要
# 向量化走本机 Ollama 的 embedding 模型，需先拉取一次：
#   ollama pull bge-m3
# 为什么是 bge-m3 而不是 nomic-embed-text：后者是英文主导模型，中文语义几乎不区分。
#   实测同一组中文对照（相关 vs 不相关）：nomic 间距 -0.020（倒挂，噪音分数高于正确答案），
#   bge-m3 间距 +0.191（可区分）。中文知识库必须用中文/多语言 embedding 模型。
# 设计原则：chromadb / Ollama 任一不可用时，Agent 照常工作（只是不带知识库），
#   绝不因 RAG 依赖缺失而启动失败。详见 rag_engine.py / experience.py 的降级逻辑。
# 常用命令：
#   python main.py --kb-add docs/            # 把目录入库
#   python main.py --kb-search "部署规范"     # 语义检索
#   python main.py --kb-status               # 知识库状态与探活
#   python main.py --exp-query "统计代码行数" # 检索历史任务经验
#   python test_rag.py                       # 四阶段端到端自检
